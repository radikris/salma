# Salma 🥂

Tinder-stílusú, játékos meghívó: **csütörtök (október 29.) 19:00, Time Out Market (Blaha Lujza tér 1.), egy pohár bor.**
A többi a második randi. 😏

Húzd jobbra a kártyát. Balra húzásnál a kártya visszajön: "Naaa, ne csináld, látni akarlak 🥺".

Statikus oldal, nincs szerver és nincs követés. A "ma" / "holnap" / "csütörtök" felirat attól függ, mikor nyitják meg.
